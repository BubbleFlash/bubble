# Командная работа над Bubble

Начни с [BUBBLE_CONTEXT.md](BUBBLE_CONTEXT.md) и сверь состояние рабочей копии. Для локального
запуска используй [DEVELOPMENT.md](docs/DEVELOPMENT.md), для прогонов — [TESTING.md](docs/TESTING.md).

- Изолируй изменение по задаче и отмечай соседние области, которые оно затрагивает.
- В PR человек указывает пользовательский эффект, затронутые контракты, результаты проверок
  и открытые ограничения. Целевую ветку и триггеры см. в [RELEASING.md](docs/RELEASING.md).
- Агент передаёт diff и результаты проверки человеку. Границы действий агента закреплены в [AGENTS.md](AGENTS.md).
- Сохраняй авторство Commune и [MIT-лицензию](LICENSE). Сообщения об уязвимостях передавай по [SECURITY.md](SECURITY.md).
